# Completion definition

THC Academy uses two distinct completion states.

## Authored system complete

The authored system is complete when the planned course catalog, modules, lessons, learning objectives, references, formative assessments, course finals, credential definitions, learner runtime, API contracts, persistence contracts, and deterministic QA are present and structurally valid. Review/readiness reports may still show external or human evidence that must be refreshed before release.

## Production certification release complete

A production certification release is complete only after the selected release scope has current-version scientific/editorial/assessment approval as applicable, reviewed and piloted production assessment pools, production issuer identity/signing and revocation, deployed authentication/authorization/MFA/RLS evidence, accessibility acceptance, staging/production environment evidence, backup/restore verification, monitoring/alerting, and a passing explicit release check.

Ordinary authoring must not be blocked merely because the second state has not yet been reached.
