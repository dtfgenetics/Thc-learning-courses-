# THC-GROW-100 Learner Guide — Disease & Disorder Diagnosis
**Draft — not operationally released**

Use a differential, not a symptom shortcut.

## Diagnostic sequence

**Observe → Map → Context → Differential → Discriminating check → Contain if needed → Confirm → Authorized action → Verify**

### Example
Patchy wilt appears in one irrigation zone.

Weak response: “It is root rot.”

Strong response: record distribution and roots; verify irrigation/moisture/aeration; compare affected and unaffected plants; keep Fusarium/Pythium and abiotic root stress in the differential; escalate sampling/testing if evidence or consequence warrants it.

### HLVd
Plants can be infected without obvious symptoms. Visual appearance cannot replace an approved testing strategy.

### Documentation
Keep observations separate from hypotheses. If the diagnosis changes, keep the earlier record and document why the ranking changed.
