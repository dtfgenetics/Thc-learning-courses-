# Controlled SOP Draft Packages

This directory mirrors the five-part controlled-package model already used by the external Drive packages:

1. scientific SOP;
2. learner guide;
3. QA/review state;
4. implementation handoff;
5. records/template set.

Repository packages are **drafts**, not released operational SOPs. A package manifest in `registry/sop-packages/` must remain `releaseState: blocked` until its release gates are evidenced. Scientific source approval does not substitute for facility-specific safety, engineering, legal, accessibility, diagnostic, or field validation where those are required.
