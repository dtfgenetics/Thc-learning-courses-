# THC-GROW-090 Learner Guide — IPM
**Draft — not operationally released**

IPM is not “see bug → spray.” Use this sequence:

**Prevent → Scout → Identify → Map → Trend → Contain → Authorized control → Verify → Close**

## Strong scouting data
Record where you looked, how much you inspected, what you actually saw, crop stage, exact location, and the method used.

## Identification confidence
A symptom is not the same thing as a pest identification. Find organism evidence when possible and use appropriate magnification/qualified identification when species matters.

## Treatment boundary
You can produce a strong diagnostic handoff without having authority to select or apply a pesticide. Current label and local/facility rules control the treatment decision.

## Verification
A treatment is not “successful” because it was applied. Recheck the crop with a compatible method and compare trend, distribution and crop injury.
