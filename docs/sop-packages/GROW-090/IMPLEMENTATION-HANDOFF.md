# THC-GROW-090 Implementation Handoff
**Version:** 0.1.0 draft — release blocked

Facility must define:
- scouting routes and sampling effort;
- pest-identification support;
- facility action/decision rules;
- quarantine and movement controls;
- approved biological/cultural controls;
- who may select/apply pesticides;
- current label/legal review process;
- follow-up timing and event-closure authority.

Pilot the workflow using at least: isolated mite finding, aphid cluster, rising trap trend with stable crop injury, treatment with mixed follow-up evidence, and pesticide request outside technician authority.
