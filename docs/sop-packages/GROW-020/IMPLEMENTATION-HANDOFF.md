# THC-GROW-020 Implementation Handoff
**Package:** Biosecurity and Clean Workflow  
**Version:** 0.1.0 draft  
**Release state:** Blocked

## Facility inputs required before implementation
- room/zone map and controlled movement routes;
- plant intake/quarantine locations;
- stock/propagation testing policy;
- approved sanitation products/methods and current instructions;
- tool/cart/equipment movement matrix;
- waste routes/containers;
- diagnostic laboratory/method contacts and sample rules;
- quarantine/release authority;
- interaction with pesticide REI, quality holds and equipment status.

## Implementation verification
Run dry simulations for: incoming cutting lot, suspect HLVd finding, contaminated tool crossing, waste removal, inconclusive test, and quarantine release.

Do not release until the facility-specific steps can be executed without ambiguous authority or uncontrolled movement.
