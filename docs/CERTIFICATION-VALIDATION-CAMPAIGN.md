# Certification Validation Campaign

The 15-course curriculum is built. The remaining work is best executed as a **seven-wave validation campaign**, not 15 independent review projects.

## Sequence

1. Occupational/technical validation — Technician I and II panels.
2. Exact-version assessment review — 13 conventional finals.
3. Rendered accessibility/UX review — can run in parallel with Waves 1–2.
4. Practical/capstone assessor calibration.
5. Controlled learner/item/practical pilots and item analysis.
6. Formal standard setting.
7. Secure operational forms and final credential authorization.

The campaign deliberately groups shared evidence by track while every approval record remains pinned to the exact course/object versions it actually covers.

## Parallelism

Accessibility review can run alongside occupational and assessment review. Technician I and II panels can also run independently. Standard setting and final authorization remain dependency-gated.

## Non-negotiable evidence boundaries

- Machine QA is not human approval.
- Academic owner approval is not occupational validation.
- Synthetic learner data is not a pilot.
- A rubric is not inter-rater calibration.
- A development pass score is not formal standard setting.
- Secure-form code is not deployed form-equivalence/security evidence.
- A credential cannot be authorized until its prerequisite course, governance and production-control evidence is complete.
