# Technician I Job-Practice Unit — Water, pH and EC Measurement

**Task:** `TASK-CULT-WATER-001`  
**Target proficiency:** Applied  
**Primary competencies:** `COMP-WATER-001`, `COMP-NUTRITION-001`  
**Prerequisite content:** `MOD-WATER-001`, `MOD-NUTRITION-001`, `LESSON-WATER-PH-002`, `LESSON-WATER-EC-003`

## What the technician is responsible for

A Cultivation Technician I should be able to collect and record basic water/nutrient-solution measurements without creating false confidence from poor sampling or meter handling.

The technician is expected to:
- identify the sample being measured
- use the supplied meter workflow correctly
- recognize when calibration/status should be checked
- record pH and EC with units/context
- distinguish pH from alkalinity
- understand that EC estimates total ionic concentration rather than individual nutrients
- avoid directly comparing unlike sampling methods
- recognize obvious outliers or suspicious meter behavior
- preserve source/feed/root-zone sample identity
- interpret repeated readings as trends when supplied
- follow the facility response procedure instead of making unauthorized nutrient changes

Technician I is not expected to independently formulate nutrient recipes or redesign irrigation chemistry.

## Measurement context comes first

Before reading a meter, identify:
- source water, feed solution, runoff/drainage or root-zone extract
- room/zone/crop identity
- sampling method
- date/time
- relationship to irrigation event
- meter ID/status when required

A number without sample context is easy to misuse.

## pH on the job

pH describes acidity/basicity and influences chemical behavior and nutrient availability.

Technician rules:
- pH and alkalinity are different properties
- a pH reading alone does not diagnose nutrient deficiency
- meter calibration and probe handling matter
- wait for a stable reading according to the meter procedure
- record the actual measured value before adjustment when the system requires it
- use supplied facility ranges rather than memorized universal targets

## EC on the job

EC indicates how readily a solution conducts electrical current and is influenced by dissolved ions.

Technician rules:
- EC does not identify which nutrient ions are present
- source, feed, runoff and extracted root-zone EC are not automatically interchangeable
- sampling method and timing matter
- repeated trends are often more useful than one isolated value
- units must be recorded correctly

## Routine measurement workflow

### 1. Confirm the sample

Label/identify before measurement.

Never allow multiple unlabeled cups to accumulate and then guess which is which.

### 2. Check the meter

Follow the supplied procedure for:
- meter ID
- calibration/check status
- probe condition
- storage condition
- rinse requirements
- temperature compensation/status if applicable

A reading from a badly maintained meter can create false precision.

### 3. Collect the sample consistently

Use the required:
- sample location
- volume
- container
- timing
- runoff/extract method

Do not compare different methods as though they are the same measurement.

### 4. Measure

- rinse/prepare probe as directed
- immerse correctly
- avoid contaminating stock/feed containers
- allow the reading to stabilize
- record pH/EC and units
- note unusual instability

### 5. Verify suspicious readings

If the result is unexpected:
- repeat according to procedure
- check sample identity
- check meter calibration/status
- compare with another approved reference/meter if procedure allows
- check source/feed context

Do not immediately make a large chemistry adjustment from one suspect reading.

### 6. Record and respond

Record:
- sample type
- location/crop ID
- pH
- EC with units
- time relative to irrigation
- meter ID when required
- expected range from supplied procedure
- repeat/verification result
- action/escalation

## Worked example 1 — Sudden pH shift after meter storage

**Situation:** The meter reads far outside the expected range immediately after a storage problem.

**Weak response:** add large amounts of pH adjuster.

**Better response:** verify/recalibrate the meter according to procedure before changing the solution.

## Worked example 2 — Similar pH, different alkalinity

Two source waters can both read pH 7.5 yet have different acid-neutralizing capacity.

**Technician lesson:** do not use pH as a substitute for alkalinity information when the facility tracks both.

## Worked example 3 — Rising root-zone EC trend

Feed EC stays stable while repeated root-zone measurements rise using the same method.

**Technician response:** document the trend together with irrigation/dryback context and escalate according to procedure. Do not automatically raise feed EC because the root-zone number is higher.

## Worked example 4 — One runoff reading

A single runoff sample is much higher than feed EC.

**Weak response:** diagnose salt accumulation from that one value without checking method/timing.

**Better response:** verify sample method, timing, identity and repeated trend.

## Worked example 5 — Source-water baseline changes

Source EC increases compared with the established baseline.

**Technician response:** record the new source value and notify the appropriate role because feed comparisons may be affected.

## Worked example 6 — Unstable probe reading

The pH reading drifts continuously.

**Technician response:** check probe condition, sample volume, calibration and procedure before recording a false precise number.

## Worked example 7 — Missing units

Record says only “EC 2.1.”

**Problem:** the value is incomplete without the unit/system context.

## Worked example 8 — Unlike methods

Drainage EC and a saturated-media extract are compared directly as if they are equivalent.

**Problem:** different sample/extraction methods can produce different values; method must remain attached to the result.

## Common Technician I mistakes

- treating pH and alkalinity as the same measurement
- adjusting from an uncalibrated meter
- using pH alone to diagnose nutrient status
- assuming EC reveals individual nutrients
- mixing sample identities
- comparing unlike extraction methods
- forgetting units
- reacting to one value without checking trend/context
- contaminating sample/feed containers with a dirty probe
- recording a suspicious unstable reading as exact

- overwritten abnormal result

## Decision scenarios

1. Meter suddenly changes after poor storage: verify calibration before adjustment.
2. EC outlier appears once: confirm method/sample/repeat before broad action.
3. Multiple repeated values trend upward: document trend and escalate.
4. Sample cups unlabeled: do not guess; recollect with proper identity.
5. pH normal but plant symptoms present: do not declare chemistry normal solely from pH.
6. Source EC baseline shifts: document because feed interpretation can change.
7. Runoff method changes: flag that new values are not directly comparable with earlier method.
8. Probe is visibly dirty: clean/prepare according to procedure before measurement.
