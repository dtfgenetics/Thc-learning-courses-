# Technician II Job-Practice Unit — Peer Task Support & Handoff

**Task:** `TASK-CULT2-PEER-001`  
**Target proficiency:** Applied  
**Primary competencies:** `COMP-PRO-SOP-001`, `COMP-CROP-PLAN-001`

## Role boundary
Technician II may demonstrate tasks, clarify SOP expectations, point out execution differences, communicate priorities and prepare supervisor-ready handoffs. Formal discipline, performance ratings, staffing, schedule ownership and training sign-off belong to Lead/Supervisor roles unless specifically delegated.

## Effective peer support
- point to the controlled work instruction
- demonstrate the critical steps
- explain why the step matters
- observe execution
- correct the task, not the person
- distinguish preference from requirement
- escalate repeated or safety/quality-critical nonconformance
- document relevant handoff information

## Worked cases

### Peer skips a required verification
Strong response: stop/correct the task if needed, reference the SOP requirement, demonstrate the verification and document/escalate if the omission affected product/process.

### Two experienced workers use different personal methods
Determine which differences are permitted variation and which conflict with the controlled procedure. Do not turn personal preference into policy.

### End-of-shift unresolved deviation
Handoff should include exact location/batch, current condition, actions already taken, open risk, next required check and owner/escalation—not “keep an eye on it.”

## Common mistakes
- acting like a supervisor without authority
- correcting from memory rather than current SOP
- using vague handoffs
- failing to explain critical control points
- hiding recurring peer errors to avoid conflict
- treating stylistic differences as deviations

## Guided practice
1. Coach a routine task using a supplied SOP excerpt.
2. Separate preference from requirement in five examples.
3. Convert vague handoff notes into actionable handoffs.
4. Identify when peer correction must become formal escalation.
5. Prioritize three competing shift tasks and communicate rationale.
