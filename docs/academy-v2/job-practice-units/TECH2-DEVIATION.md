# Technician II Job-Practice Unit — Cultivation Deviation Investigation

**Task:** `TASK-CULT2-DEVIATION-001`  
**Target proficiency:** Diagnostic  
**Primary competencies:** `COMP-PRO-QA-001`, `COMP-PRO-SOP-001`

## Purpose
A deviation is a documented difference between what should have happened and what actually happened. Technician II should be able to contain immediate impact, capture facts, identify affected scope and assemble an evidence package without inventing a root cause or changing records to make the event disappear.

## Investigation workflow

### 1. Stabilize/contain
Protect people, crop, identity and records using the governing procedure.

### 2. State the deviation factually
Include what, where, when, expected condition and observed condition.

### 3. Identify the governing instruction
Record SOP/work-order ID and version. A deviation cannot be evaluated against an undefined expectation.

### 4. Define affected scope
Use room, batch, lot, equipment, time and genealogy evidence.

### 5. Build timeline
Include work events, measurements, alarms, movements and discoveries.

### 6. Separate facts from cause hypotheses
A suspected cause remains a hypothesis until evidence supports it.

### 7. Preserve corrections and follow-up
Never overwrite the original event. Record what was corrected, by whom/when, and what still requires disposition.

## Worked cases
- irrigation event missed on one zone: identify exact zone/time, affected plants, controller history and recovery checks
- wrong SOP version used: preserve the actual version used and compare material differences
- sanitation step omitted: contain affected movement/tools and identify downstream contact scope
- label mismatch: stop movement and reconcile genealogy before combination or downstream processing

## Common mistakes
- writing a cause as fact before investigation
- defining scope from memory instead of records
- backfilling a perfect record
- omitting the SOP/version
- fixing the immediate problem but failing to document recurrence risk

## Guided practice
1. Rewrite vague deviation statements into factual event statements.
2. Build a timeline from mixed logs.
3. Separate facts, hypotheses and missing evidence.
4. Map affected scope from genealogy and time.
5. Draft a supervisor/QA-ready deviation package.

## Practical mapping
Deviation reasoning is embedded across Practicals F and G and the Senior Technician Diagnostic Shift capstone.

## Portfolio artifact
**Cultivation Deviation Investigation Packet** containing event statement, timeline, affected scope, evidence, immediate containment and open follow-up.

## Completion standard
The learner can document and investigate routine cultivation deviations in a way that preserves evidence, traceability and decision quality.
