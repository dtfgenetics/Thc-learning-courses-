# Technician II Job-Practice Unit — Production Metrics & Trend Review

**Task:** `TASK-CULT2-METRICS-001`  
**Target proficiency:** Applied  
**Primary competencies:** `COMP-CROP-PLAN-001`, `COMP-PRO-QA-001`

## Purpose
Metrics turn routine cultivation records into operational feedback. Technician II should calculate basic KPIs correctly, understand denominators/time windows, identify meaningful trends and avoid presenting a percentage without context.

## Core metrics
Examples include:
- propagation rooting/survival success
- plant-loss rate
- task completion/on-time rate
- irrigation water/use per room or plant
- emitter/uniformity exceptions
- IPM incidence/severity trend
- harvest yield per defined denominator
- dry-room/process exception rate
- rework/deviation frequency
- labor/task duration when available

## Metric discipline
Every KPI needs:
- clear numerator
- clear denominator
- defined time window
- population/scope
- comparable method
- context for major process changes

## Worked cases

### Rooting rate rises but cull rate also rises
A single success metric can hide later quality losses. Review the full process outcome.

### Yield increases after plant count increases
Total yield alone does not prove per-plant or per-area performance improved. Use the correct denominator.

### IPM incidence falls because fewer plants were sampled
Normalize sampling before claiming improvement.

### Task completion improves but deviations increase
Speed/throughput is not the only quality dimension. Interpret competing metrics together.

## Common mistakes
- changing denominator between periods
- comparing different crop stages as if equivalent
- reporting totals without exposure/population context
- celebrating one KPI while ignoring quality loss
- inferring causation from correlation alone

## Guided practice
1. Calculate eight common cultivation KPIs.
2. Detect denominator errors.
3. Build a simple multi-cycle trend table.
4. Identify when a KPI change is explained by a process/population change.
5. Write a two-paragraph operational interpretation without overclaiming causality.

## Completion standard
The learner can calculate and interpret routine cultivation metrics accurately and use them as evidence for operational follow-up rather than as isolated scorekeeping.
