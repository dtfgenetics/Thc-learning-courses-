# Technician II Job-Practice Unit — Propagation Performance Troubleshooting

**Task:** `TASK-CULT2-PROP-001`  
**Target proficiency:** Diagnostic  
**Primary competencies:** `COMP-PROP-001`, `COMP-IPM-ADV-001`, `COMP-PRO-QA-001`  
**Prerequisite:** Technician I Propagation + Sanitation/IPM

## What changes from Technician I
Technician I executes a clean propagation batch. Technician II compares batches and investigates why rooting, survival, uniformity or contamination performance changed.

## Evidence streams
- donor identity and condition
- cut/date/operator/batch genealogy
- cutting size/quality observations
- sanitation and tool history
- environment and moisture-management trend
- rooting/survival milestones
- cultivar/genotype timing
- tray/zone spatial pattern
- contamination signs
- media/input lot changes
- process/SOP changes

## Troubleshooting workflow
1. Define the performance metric and time window.
2. Compare affected versus normal batches.
3. Separate genotype timing from process failure.
4. Map losses by tray, zone, operator, donor and date.
5. Review environment/sanitation/process changes.
6. Rank plausible causes and select the next discriminating check.
7. Verify response after a controlled correction.

## Worked cases

### One donor group underperforms
Multiple trays from one donor group root slowly while other donors under identical room conditions perform normally.

Best direction: investigate donor/genotype condition and source history before changing the whole-room environment.

### One bench has contamination
Losses cluster on one bench and share a tool/workflow path.

Best direction: preserve the spatial/process association, review sanitation and movement history, isolate concern and avoid assuming genetics.

### All batches slow after environmental change
Several genotypes slow after a room humidity/temperature control change.

Best direction: evaluate common environmental/process timing before blaming donor quality.

## Common mistakes
- comparing batches at different ages without normalizing time
- calling slow genotype response a failure without historical context
- changing hormone/input, environment and media simultaneously
- ignoring operator or sanitation patterns
- using final survival percentage without examining when losses occurred

## Guided practice
1. Calculate rooting and survival rates by batch and donor.
2. Plot loss timing and identify the strongest process association.
3. Compare genotype-specific historical rooting windows.
4. Build a propagation differential from donor, environment and sanitation evidence.
5. Select one controlled process check rather than multiple simultaneous changes.

**Practical E — Propagation/Canopy Performance Review** may generate a propagation form requiring batch comparison and corrective-verification planning.

## Completion standard
The learner can diagnose routine propagation underperformance using comparative batch evidence, distinguish genotype effects from shared process failures, and recommend verification/correction within SOP authority.
