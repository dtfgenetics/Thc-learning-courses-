# Technician II Course 008 Build Status

Course 008 is built as the integrated Technician II simulation lab. It adds a dedicated lab module, four applied integration lessons, eight course-specific objectives, a 16-item formative readiness check, and LABPLAN-TECH2-001 covering all seven practicals plus the Senior Technician Diagnostic Shift capstone.

The lab is deliberately non-compensatory: every practical must independently meet 80% with no critical errors, and the capstone must meet 80% with no critical errors. The readiness check is formative only and cannot substitute for performance evidence.

Course and program remain draft. Human technical/assessment review, accessibility review, employer/job-task validation, pilot/performance evidence, evaluator calibration, equivalent secure forms, standard setting, candidate-evidence retention/privacy controls and explicit release approval remain required.
