## What still blocks professional release

Across the course ledgers, the remaining work is evidence that must be executed or independently reviewed:

- technical/occupational SME review;
- human assessment review;
- learner/item pilots and item statistics;
- practical/capstone validation;
- paired-assessor calibration/inter-rater evidence;
- rendered WCAG 2.2/accessibility and responsive review;
- form-equivalence/security evidence;
- formal standard setting;
- privacy/security/retention approval;
- final credential/program authorization.

This distinction prevents the global Academy `substantiveContentComplete` flag from being misused as a certification-course completion flag.
