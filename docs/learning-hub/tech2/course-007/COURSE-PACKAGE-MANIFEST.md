## Controlled learning outcomes
1. Reconcile physical and recorded crop/lot identities while preserving genealogy and controlled correction evidence.
2. Calculate defined production KPIs with the correct denominator, eligible population and time window, then interpret trends without overstating one-cycle changes.
3. Support peer execution using the current controlled procedure while preserving formal supervisory, approval and record-change authority boundaries.
4. Prioritize unresolved work and produce a decision-ready shift handoff that preserves planned-versus-actual history, dependencies and decision ownership.
