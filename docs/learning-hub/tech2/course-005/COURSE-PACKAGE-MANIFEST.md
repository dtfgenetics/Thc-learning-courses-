## Controlled learning outcomes
1. Calculate and compare propagation performance using traceable donors, batches, denominators, time points and loss distributions.
2. Troubleshoot propagation underperformance using donor, sanitation, environment, handling, timing and plant-health evidence without unsupported contamination or genotype claims.
3. Evaluate canopy and flowering work using planned-versus-actual scope, spatial uniformity, recovery and cultivar/stage context.
4. Produce a reconstructable performance review and supervisor handoff while maintaining sanitation, traceability, role and authorization boundaries.
