# Course 7 Integrated Lab Accessibility & UX Review

**Course:** `COURSE-LH-TECH1-007`  
**Target:** WCAG 2.2 AA plus equitable practical/capstone administration  
**State:** review packet prepared; approval open

## Scope

Review:

- all four integrated-lab lessons;
- readiness assessment;
- practice/readiness mode interfaces;
- practical preparation and candidate packets;
- capstone simulation/interface;
- dynamic-event notifications;
- shift logs, maps, tables and worksheets;
- scoring/evaluator tools where accessibility affects administration;
- sanitized performance summary.

## Digital learner checks

- keyboard-only operability;
- visible focus and logical order;
- screen-reader semantics/labels;
- no color-only meaning for hazard/hold/status states;
- zoom/reflow at phone/tablet/desktop widths;
- accessible tables/maps with text alternatives;
- non-hover access to important evidence;
- usable timed-event behavior without inaccessible surprise interactions;
- errors/status updates announced programmatically where needed;
- sufficient time controls in practice/readiness modes.

## Integrated-simulation checks

Dynamic event injects must not rely solely on sound, color or animation. The learner must receive an equivalent perceivable indication while preserving the competency demand.

## Practical/accommodation review

For each practical/capstone behavior, identify:

- the competency construct being measured;
- whether a sensory/motor behavior is essential to that construct;
- whether an accommodation changes only access or changes the construct itself;
- approved equivalent evidence where appropriate;
- how the accommodation is recorded without disclosing unnecessary private health information to evaluators.

## Time/access considerations

Any time limits should be justified by the competency rather than convenience. Where speed is not an essential construct, accommodations may change administration time without changing scoring expectations for the underlying task.

## Maps/images/scouting evidence

Provide meaningful nonvisual/text evidence alternatives where doing so preserves the observation/decision construct. If direct visual recognition is genuinely part of the intended competency, document that construct explicitly and review accommodation options through credential governance rather than silently excluding candidates.

## Assessment security versus accessibility

Secure forms must remain accessible. Do not solve security by disabling assistive technologies, keyboard navigation or legitimate accommodations. Accommodation delivery should minimize unnecessary exposure of secure content while preserving equal access.

## Responsive review

Test representative phone, small-tablet, tablet, desktop and wide-desktop layouts for learner-facing material. Credential-mode practical administration should be reviewed on the actual supported devices/environment rather than assumed from development source.
