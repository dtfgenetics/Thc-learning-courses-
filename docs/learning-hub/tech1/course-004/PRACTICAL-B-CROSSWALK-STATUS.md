# Course 4 Practical B Crosswalk Status

Course 004 now has explicit development-stage performance mapping to `PRACTICAL-TECH1-B` for all six course objectives.

The mapping is governed by `registry/course4-practical-b-crosswalk.json` and verified by `scripts/test-course4-practical-crosswalk.mjs` through the normal Course 004 regression.

## Coverage added

Practical B now includes bounded nutrition-context interpretation using the supplied symptom pattern, developmental stage, pH/EC, root-zone and irrigation evidence. The candidate must separate observations from possible explanations and must not assign a nutrient deficiency, excess or antagonism without supporting evidence.

This closes the Course 004 objective-3 development gap without authorizing nutrient recipe changes, treatment selection, equipment repair or crop-strategy redesign.
