## Production requirements for individual assets

Each production lesson graphic derived from these references must:

1. have one primary instructional purpose;
2. be exported as an individual full-resolution asset rather than a crop from a composite board;
3. use accurate, human-readable text rather than relying on image-generation text for final instructional wording;
4. include a caption and meaningful text alternative;
5. carry a persistent visual asset ID and revision/version;
6. map to the relevant lesson objective(s), activity and/or assessment construct;
7. record source/provenance when factual claims or recognizable source material are represented;
8. avoid presenting facility-specific practices as universal rules;
9. preserve Course 1 authorization/escalation boundaries;
10. pass visual, factual, accessibility and responsive-layout QA before learner-facing publication.
