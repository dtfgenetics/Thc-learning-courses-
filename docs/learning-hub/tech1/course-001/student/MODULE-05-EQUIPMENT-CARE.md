# Module 5 — Equipment Readiness, Operator Care & Fault Reporting

## Why this module matters

Cultivation depends on pumps, fans, irrigation components, lights, carts, hand tools, sensors, controllers, dehumidification/HVAC equipment and other assets. Technician I does not need to become a maintenance specialist, but must notice obvious unsafe or abnormal conditions, complete assigned operator checks, protect safeguards, and provide useful information when equipment needs technical service.

OSHA machine-guarding material emphasizes that moving machine parts can cause severe injury and that safeguards protect operators and nearby employees. OSHA hazardous-energy requirements also show why servicing is different from normal operation: unexpected startup or release of stored energy can injure workers.

**Controlled references:** `REF-OSHA-MACHINE-GUARDING`, `REF-OSHA-1910-147-LOTO`, `REF-NIOSH-CANNABIS-HAZARDS-2024`, `REF-WHO-DATA-INTEGRITY-2021`.

## Lesson 5.1 — Equipment pre-use and readiness checks

### Check before operation

A pre-use check is a defined inspection intended to catch obvious readiness problems before they become worker injury, crop damage, process failure or downtime. The exact checklist belongs to the equipment manufacturer and facility procedure, but common categories include:

- correct asset identity;
- required cleanliness/sanitation state;
- visible damage;
- leaks;
- secure hoses/connections;
- guards or protective devices present;
- cords/plugs where relevant;
- abnormal sounds or odors before/at startup;
- warning indicators;
- calibration/readiness status where assigned;
- clear work area.

### A failed readiness check changes the task

If a required guard is missing, a cord is damaged, a line leaks unexpectedly, or another acceptance condition fails, follow the out-of-service/escalation procedure. Do not compensate for a missing safeguard with “extra careful” behavior.

### Worked case

A trimming or processing device has a missing guard but production is behind schedule. The machine still runs. The correct response is not to use it carefully; the missing safeguard changes equipment status. Follow the site’s out-of-service process and escalate.

### Guided practice — pre-use inspection

Inspect a simulated asset using a checklist containing eight conditions. Classify each finding as:

- acceptable;
- routine operator correction;
- out-of-service/maintenance escalation;
- emergency hazard.

Then document the asset identity and decision.

### Retrieval check

1. Why are yesterday’s successful operations not proof that today’s pre-use check can be skipped?
2. What is the purpose of a safeguard?
3. What should happen when a readiness criterion fails?

## Lesson 5.2 — Routine operator care versus skilled maintenance

### Operator care is explicitly assigned

Operator care can include external cleaning, inspection, simple setup, replacement of consumables, checking visible connections, or other tasks that the equipment manual and site SOP assign to the operator.

The key phrase is **assigned to the operator**. Technician I should not expand the task because the repair looks simple.

### Servicing changes the hazard picture

Tasks can move into servicing when they require:

- removing/bypassing guards;
- reaching into hazardous motion areas;
- disassembling powered equipment;
- opening protected electrical components;
- releasing pressure/stored energy;
- clearing jams where unexpected startup is possible;
- other maintenance covered by the employer’s energy-control procedure.

OSHA 1910.147 requires appropriate energy-control procedures for covered servicing and distinguishes authorized employees from affected workers. Course completion does not make the learner an authorized lockout/tagout worker.

### Worked case

An irrigation filter appears clogged. The operator procedure allows an external pressure reading and visual leak inspection. Clearing the suspected blockage requires disassembling a pressurized component. The technician stops at the assigned operator checks and refers the service task.

### Guided practice — find the boundary

For ten equipment scenarios, draw a line between **operator care** and **servicing**. For each servicing task, state what information should be passed to maintenance instead of attempting the repair.

### Retrieval check

1. Why is “I know how” different from “I am authorized”?
2. Give two examples of stored or hazardous energy.
3. When can an operator check become a servicing task?

## Lesson 5.3 — Alarms, fault context and maintenance escalation

### An alarm is evidence, not a root cause

A controller alert, failed zone, unusual noise, leak or abnormal reading is a symptom. It can narrow the investigation, but Technician I should not declare a root cause without evidence.

Useful fault context includes:

- asset ID;
- location/zone;
- exact time;
- alarm code/message;
- relevant readings;
- visible condition;
- operator checks completed;
- process/crop impact;
- safe action already taken;
- person/ticket notified.

### Repeated resetting can hide the problem

Resetting an alarm without understanding the permitted procedure can erase useful context or allow repeated failure. If the operator SOP permits one reset after defined checks, follow it. If the condition returns or the procedure does not authorize reset, escalate.

### Worked case

Pump `P-12` alarms at 14:10. Tank level is normal, no visible leak is present, and Zone 3 receives no flow. The operator checklist is complete. A strong escalation states those facts. “Pump broken” is too vague; opening the control cabinet would exceed Technician I authority.

### Guided practice — write the maintenance ticket

From a simulated dashboard, room map and operator checklist, write a maintenance-ready escalation using only observable facts. Separate:

- observation;
- permitted test/check;
- result;
- impact;
- hypothesis if allowed, clearly labeled as unconfirmed.

### Module application — equipment fault report

Complete a portfolio-ready simulated report containing:

- pre-use inspection;
- alarm timeline;
- allowed checks;
- out-of-service decision;
- maintenance escalation;
- affected-task handoff.

### Module retrieval

Explain why a technician who **does not** attempt an unauthorized repair may be demonstrating stronger competence than one who successfully improvises a repair outside procedure.
