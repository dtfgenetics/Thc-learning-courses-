# Job Aid 5 — Equipment Readiness and Fault Escalation

## Pre-use categories

Check the items assigned by the equipment/site procedure, such as asset identity, cleanliness/sanitation state, visible damage, leaks, connections, guards/protective devices, cords/plugs, warning indicators, calibration/readiness status where assigned, and work-area clearance.

## Classify the finding

- **Acceptable** — meets the readiness criteria.
- **Routine operator correction** — explicitly assigned and safe within the operator procedure.
- **Out of service / maintenance escalation** — failed readiness condition or repair beyond operator scope.
- **Emergency hazard** — follow emergency/stop-work process immediately.

## Operator care versus servicing

Technician I should stop and escalate when the task requires removing/bypassing guards, reaching into hazardous motion, opening protected electrical components, disassembling pressurized equipment, releasing stored energy, or other servicing outside assigned authority.

## Fault report formula

**Asset ID + location + time + exact observation/alarm + readings + permitted checks + results + process/crop impact + safe action already taken + who/ticket notified.**

Separate observation from hypothesis. “Zone 3 has no flow while tank level is normal” is evidence; “pump motor failed” is a diagnosis unless confirmed.
