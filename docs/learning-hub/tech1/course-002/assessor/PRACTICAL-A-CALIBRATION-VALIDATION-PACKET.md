## Validation claims to examine

Human reviewers and pilot evidence should determine whether the practical supports the following limited claims:

1. candidates can execute safe entry and basic biosecurity procedures in the supplied scenario;
2. candidates can perform a systematic, identity-preserving crop inspection;
3. candidates can distinguish observation from unsupported diagnosis;
4. candidates can interpret routine supplied environmental/sensor context at an entry-level operator boundary;
5. candidates can produce traceable records and actionable handoff/escalation evidence;
6. when a light-verification station is used, candidates can collect and document a repeatable canopy grid under supplied measurement conditions without redesigning the lighting strategy.

Claims beyond these boundaries require separate evidence.

## Phase 2 — assessor calibration

### Calibration setup

Before operational scoring, candidate assessors should complete orientation using the same controlled scoring categories and administration rules. Use multiple benchmark performances or standardized simulations that deliberately include clear, borderline and incomplete evidence.

At minimum, the calibration set should sample:

- safe-entry/hazard decisions;
- sanitation/biosecurity execution;
- representative versus convenience crop inspection;
- observation versus unsupported diagnosis;
- sensor representativeness and operator-scope decisions;
- documentation/traceability quality;
- handoff/escalation quality;
- light-verification evidence when that station will be used operationally.

### Agreement evidence

Record the selected agreement statistics before calculating them. Appropriate metrics depend on score type and sample size. The validation team should at minimum report:

- exact/near-exact agreement for any categorical safety/identity decisions;

## Phase 3 — response-process and administration review

Observe pilot administrations to determine whether candidates and assessors interpret directions as intended. Record:

- requests for clarification;
- assessor prompts/interventions;
- scenario ambiguities;
- equipment or simulation failures;
- time-pressure effects unrelated to the intended construct;
- whether candidates can distinguish supplied targets/limits from measured values;
- whether the operator-care boundary is understood;
- whether documentation forms elicit the intended evidence.

Revise the task or directions when recurrent misunderstandings reflect the instrument rather than candidate performance.

## Phase 5 — pass-score / decision-rule review

The canonical practical currently carries a **development target pass of 80/100**. That number must not be presented as empirically validated merely because it appears in the source document.

Before approving an operational cut score:

1. define the intended interpretation of passing performance;
2. convene qualified judges using an approved standard-setting method suitable for the performance task;
3. review category weighting, compensatory effects and the separate serious safety/identity correction boundary;
4. review pilot score distributions as supporting evidence, not as the sole standard-setting method;
5. document judge instructions, ratings, discussion rounds, final recommendation and governance approval;
6. version the resulting decision rule.

## Phase 6 — fairness and accessibility review

Review whether any task or delivery feature adds a barrier unrelated to the competency. Examine:

- readability and terminology;
- color/visual dependence;
- alternative access to visual information where compatible with the target construct;
- physical-access assumptions;
- assistive-technology compatibility for records/forms;
- unnecessary speed dependence;
- language or cultural assumptions unrelated to cultivation work;
- equipment familiarity not taught or supplied;
- consistent accommodation handling.

Record changes and recheck whether they alter score interpretation or require re-calibration.

## Phase 7 — equivalent-form and scenario controls

Operational forms may vary seeded conditions, room maps, plant IDs, readings or meter outputs only when they preserve the same competency demand and scoring model.

For each form, record:

- form/scenario ID and version;
- task/category coverage;
- required seeded conditions;
- expected evidence;
- supplied targets/limits and instrument context;
- known answer/scoring anchors kept out of learner materials;
- technical review status;
- comparability review status.

Material changes to task demand, category weighting or decision rules require review as a new version rather than silent substitution.
