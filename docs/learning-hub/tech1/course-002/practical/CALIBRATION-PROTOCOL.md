# Course 2 / Practical A Evaluator Calibration Protocol

**Course:** `COURSE-LH-TECH1-002`  
**Practical:** `PRACTICAL-TECH1-A`  
**State:** protocol prepared; no calibration or inter-rater evidence is claimed

## Purpose

This protocol defines how evaluators should be calibrated before Practical A evidence is used for a professional Technician I decision. It provides a repeatable process while keeping actual calibration completion, inter-rater evidence and approval as genuine human/evidence gates.

## Preconditions

Before a calibration session, all evaluators should receive the same controlled versions of:

- Practical A;
- Course 2 Practical A crosswalk;
- Course 2 assessor guide;
- scoring rubric/category definitions;
- candidate packet and seeded-condition rules;
- current remediation/reassessment policy;
- approved accommodation and safety-intervention rules.

The session lead records document versions so later scoring evidence can be tied to the exact baseline used.

## Calibration exercise

1. **Independent review** — evaluators read the controlled practical and scoring guidance without discussing a sample candidate.
2. **Common evidence sample** — all evaluators receive the same representative synthetic or pilot-derived candidate evidence packet.
3. **Independent scoring** — each evaluator scores the packet before group discussion.
4. **Variance analysis** — compare category scores, critical-error judgments, evidence sufficiency decisions and remediation/reassessment dispositions.
5. **Rule clarification** — resolve differences by pointing to the controlled criteria; do not create undocumented local rules during discussion.
6. **Second independent sample** — score a different equivalent evidence packet after clarification.
7. **Readiness decision** — document whether evaluator agreement is sufficient under the program's approved calibration standard. If the program has not yet approved that standard, record the evidence without inventing a pass threshold.

## Cases that calibration must include

The calibration set should include at least one example of each of the following before professional use:

- strong representative crop walk and reconstructable record;
- technically useful observation with an unsupported diagnosis added;
- incomplete identity/context that weakens otherwise accurate observations;
- appropriate uncertainty and escalation;
- unauthorized action outside Technician I authority;
- safety or identity condition requiring intervention/correction;
- borderline total score where criterion-level evidence matters;
- equivalent-form variation that should not change the competency standard.

## Evidence to retain

For every calibration cycle, retain:

- date/session identifier;
- practical, rubric, assessor-guide and crosswalk versions;
- evaluator identities/qualification status according to the approved privacy model;
- common sample/form identifiers;
- independent scores before discussion;
- disagreement categories;
- clarification decisions and controlled-source references;
- second-round independent scores;
- unresolved scoring questions;
- approval or follow-up decision by the authorized human reviewer.

## Inter-rater evidence

The program may select an appropriate agreement statistic or documented decision rule based on sample size, scoring scale and use case. This protocol does not prescribe or fabricate a numerical reliability threshold before the credential governance process approves one.

At minimum, the retained evidence should allow reviewers to determine whether evaluators consistently apply:

- systematic crop-inspection criteria;
- observation-versus-diagnosis boundaries;
- documentation/traceability expectations;
- escalation/authority limits;
- safety/identity intervention rules;
- equivalent-form expectations.

## Recalibration triggers

Recalibration should be considered when any of the following occurs:

- material change to Practical A tasks, scoring weights or critical-error rules;
- material change to the Course 2 crosswalk or assessor guide;
- new equivalent form/scenario design that changes evidence presentation;
- repeated scoring disagreement or appeal pattern;
- evaluator lapse/extended inactivity defined by the operating program;
- pilot or operational data showing unexpected scorer effects.

## Boundary

Completion of this document means the calibration **process is defined**. It does not mean evaluators have been calibrated, inter-rater reliability is acceptable, Practical A is validated, or the credential is releasable.
