# THC Academy Occupational Architecture V2

## Build principle

THC Academy should create content freely and continuously. The occupational framework exists to organize that content around useful employment outcomes, not to slow production.

Only structural failures should block development: invalid source objects, broken references, duplicate IDs, or a credential claiming competencies/tasks that are not mapped.

Accreditation, employer validation, psychometrics, external standards, internships, college articulation, and advanced governance remain quality-improvement workstreams. They can be added as the system matures without preventing course/content production.

## Core chain

Occupation -> Role -> Task -> Competency -> Proficiency -> Course/Lesson -> Practice -> Assessment -> Credential

## Initial target

The first employment-facing target is Cultivation Technician I. Its initial task set covers workplace safety, sanitation/biosecurity, crop observation, environmental monitoring, water/solution measurement, irrigation execution, IPM scouting, propagation, canopy work, harvest, postharvest, and cultivation records.

This is intentionally a starter profile. We will expand it rapidly from job-market research, existing THC content, employer feedback, and specialist-course development.

## Proficiency scale

1. Awareness
2. Foundational
3. Applied
4. Operational
5. Diagnostic
6. Lead

## Parallel content expansion

While the role framework expands, content production should continue across Foundations, Technician I, Technician II, specialist pathways, advanced cultivation, home cultivation, outdoor/greenhouse, genetics/breeding, tissue culture, quality systems, and leadership/operations.

Questions, scenarios, practicals, visuals, simulations, worksheets, glossaries, references, and portfolio work should be produced alongside lessons rather than waiting for all governance work to finish.
