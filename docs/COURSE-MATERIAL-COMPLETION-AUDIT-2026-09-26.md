# Course Material Completion Audit — 2026-09-26

## Scope

This audit covers the canonical THC Academy Technician certification curriculum in `dtfgenetics/Thc-learning-courses-`.

## Confirmed structure

- 15 canonical certification courses.
- 7 Technician I courses.
- 8 Technician II courses.
- 13 conventional course finals.
- Technician I Course 7 and Technician II Course 8 use integrated performance/capstone paths rather than conventional finals.
- The legacy/encyclopedia 420-topic catalog is reference material and is not the certification-course count.

## Main problem found

The project has accumulated more planning, registries, schemas, release controls, and historical course/resource shells than the learner experience needs to see. The current repository status says all 15 canonical certification courses are machine-constructed, yet the learner-facing quality still depends on content-depth signals such as worked examples, common mistakes, application practice, remediation, instructional images, job aids, and integrated scenarios.

This means the next phase should not create more empty course records. It should finish and deepen the existing 15-course learner layer.

## Placeholder policy

Public learner material must not contain unresolved production language such as:

- TODO / TBD
- lorem ipsum
- “insert image here”
- “coming soon”
- placeholder copy
- fake download links
- empty source/reference slots
- internal production notes presented to learners

Normal HTML input placeholder attributes are not course-content defects and should not be counted as instructional placeholders.

## Required lesson-quality baseline

Every certification lesson should be reviewed against the following minimum:

- meaningful overview and explicit objective alignment;
- substantive scientific/technical explanation;
- cannabis-specific context without overstating evidence;
- worked example or applied example;
- common mistakes/misconceptions;
- practical/application component;
- knowledge check or mapped assessment;
- authoritative references;
- remediation/retry guidance where applicable;
- instructional raster visual when a visual materially improves understanding.

## Visual-material rule

Production course visuals should be raster assets (PNG/WebP/JPEG), high resolution, legible on mobile, and tied to a learning objective. Decorative filler does not count as instructional coverage. SVG remains excluded from production instructional visual assets.

## Execution rule

Finish content in canonical course order, beginning with Technician I Course 1 and moving forward. A course pass should include lesson depth, sources, assessments, job aids, visuals, responsive rendering, and learner remediation before moving to the next course.

## Certification boundary

Machine completion, source records, owner approval, or generated evidence templates cannot substitute for human technical review, pilot evidence, accessibility review, psychometrics, standard setting, security/privacy validation, or credential authorization.
