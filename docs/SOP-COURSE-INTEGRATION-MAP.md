# SOP ↔ Certification Course Integration Map

The 17 repository-native SOP draft packages are now mapped back to the existing certification curriculum.

## Rule

A draft SOP package is **not** automatically a learner-facing approved operational procedure.

The existing course lessons may continue to teach the underlying reviewed science, diagnostic reasoning, recordkeeping, safety boundaries and authority principles. The draft SOP itself stays an internal review/implementation artifact until exact-version release approval is recorded.

## Coverage

- 17/17 SOP drafts map to existing canonical modules.
- 17/17 SOP drafts map to existing lessons.
- 0/17 are operationally released.
- No new parallel curriculum is required.

## Promotion path

When a package is independently approved for the exact version:

1. create/update a controlled resource/download record;
2. preserve the approved package version and source set;
3. attach explicit course/module/lesson mappings;
4. record rendered accessibility state;
5. record any facility/jurisdiction limitation;
6. expose the learner-facing resource only after the release record is approved.

This keeps the certification courses and SOP system connected without confusing education with operational authorization.
