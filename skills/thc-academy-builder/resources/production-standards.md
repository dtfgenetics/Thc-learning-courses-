# THC Academy production standards

These are production defaults, not bureaucracy. Adjust when a better instructional design is justified.

## Reuse / upgrade / create decision

For every requested content area classify existing material as:

- **Reuse** — science/content is already strong; link it into the credential.
- **Upgrade** — canonical content exists but needs more examples, evidence, visuals, practice, accessibility or current references.
- **Create** — the missing layer truly does not exist, especially job practice, scenarios, practicals, simulations, role mapping or credential evidence.

Avoid parallel factual copies of the same topic.

## Job-practice unit standard

A strong employment unit normally contains:

- task ID and target proficiency;
- role boundary;
- prerequisites/canonical lessons;
- workplace outcome;
- repeatable workflow;
- evidence/measurement inputs;
- worked cases;
- common mistakes;
- guided practice;
- 6–12 decision/troubleshooting scenarios for major units;
- documentation/traceability exercise;
- practical mapping;
- portfolio artifact;
- completion standard.

## Lesson V2 capabilities

Schemas/content should be able to support:

- why it matters;
- prerequisite retrieval;
- measurable objectives;
- core explanation and vocabulary;
- figures/photos/infographics with captions/alt text;
- worked examples;
- misconceptions;
- guided practice;
- decision scenarios;
- calculations/data exercises;
- workplace/SOP link;
- safety/compliance note where relevant;
- formative checks;
- practical/lab/simulation;
- summary/spaced retrieval;
- sources and further reading.

Do not require every element in every lesson.

## Question-writing standard

Every credential item should have a clear reason for existing.

Required qualities:

- maps to competency and objective when available;
- one defensible best answer for single-select items;
- plausible distractors derived from realistic mistakes;
- rationale explains reasoning, not merely the key;
- evidence/references where the schema expects them;
- avoids trick wording and trivia;
- avoids unsupported universal targets;
- uses stage, cultivar, substrate, equipment, environment, or SOP context when the answer depends on context.

Useful item types include:

- applied multiple choice;
- calculation/data interpretation;
- trend comparison;
- diagnostic next-step selection;
- evidence-quality judgment;
- image/symptom identification when suitable assets exist;
- SOP sequencing;
- traceability/reconciliation;
- scenario decisions.

## Question-bank density defaults

Use production plans when present. Otherwise reasonable seed targets are:

- small foundational lesson: 8–15 items;
- major Foundations domain: 20–40+ items;
- Technician I job task: begin around 10–20 role-focused items;
- Technician II major diagnostic/system task: begin around 15–25 items;
- specialist domain: build enough depth for multiple randomized forms and scenario diversity;
- mature employment credentials should have substantially larger banks than one exam form.

## Practical standard

A practical should include:

- candidate brief/work order;
- supplied data/equipment/simulation state;
- required actions/decisions;
- required records;
- observable scoring criteria;
- critical-error handling where safety/traceability warrants it;
- assessor/simulation notes;
- linked task/competency/proficiency;
- portfolio output.

Allow simulation, supervised lab, and/or approved workplace equivalents when appropriate.

## Capstone standard

A capstone should integrate multiple systems. It should test prioritization, evidence quality, execution/diagnosis, documentation, and handoff. Avoid making it a long quiz disguised as a capstone.

## Portfolio standard

Employment credentials should produce artifacts employers can understand, for example:

- crop diagnostic report;
- environmental/sensor investigation;
- fertigation verification;
- irrigation/root-zone analysis;
- IPM scouting/treatment follow-up;
- propagation performance report;
- canopy response report;
- postharvest deviation report;
- traceability reconciliation;
- KPI/trend analysis;
- SOP/deviation record;
- integrated shift summary.

## Visual/media standard

Visuals are instructional objects, not decoration. Prefer diagrams, annotated photographs, maps, process flows, symptom comparisons, dashboards, data visualizations, decision trees, equipment diagrams and job aids that support a defined objective.

When asset metadata is available, connect:

`asset -> objective/competency/lesson -> caption -> alt text -> evidence/source -> revision`

## Scientific/evidence standard

Prefer an evidence stack rather than one source when a topic is foundational or contested. Distinguish:

- authoritative standards/reviews/reference texts;
- controlled peer-reviewed horticulture/CEA research;
- controlled cannabis-specific research;
- university/extension/government guidance;
- documented expert consensus;
- emerging/grower observation.

State limitations and context. Do not turn one cannabis study into a universal target rule.

## Credential naming standard

Favor role-recognizable or capability-recognizable names. A credential should make sense on a resume without requiring a paragraph of explanation.

Do not label ordinary Academy course completion as independent professional certification, government licensure, or external accreditation.
